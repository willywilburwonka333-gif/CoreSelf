# Core Self Genesis 1.2 — Dylan Identity Core

Genesis 1.2 moves Core Self closer to its actual purpose: a private, evolving AI version of Dylan rather than a generic assistant with tools.

## Identity foundation

- Adds a structured confirmed model of Dylan: purpose, prime directive, roles, values, traits, preferences, goals, communication style, decision rules, projects and boundaries.
- Starts Dylan Core in the **Bonding** development stage.
- Shows identity-foundation progress using confirmed learning and memory depth.
- Development-stage changes require Dylan to press the advance button; Core Self cannot silently promote itself.

## Learning loop

- Talk detects statements that may describe Dylan’s identity, values, preferences, relationships or goals.
- These become **pending identity learnings**, not automatic facts.
- Dylan accepts or rejects each proposal from the Core screen.
- Accepted changes are saved to the confirmed Identity Core and written to the audit trail.

## Identity-aware replies

- The confirmed Identity Core is included in the model context before memories, projects and current conversation.
- The model is instructed to preserve Dylan’s voice and continuity while separating confirmed truth, memory, inference and uncertainty.
- Settings includes a local-only privacy mode that stops identity context from being sent to the AI provider.

## Persistence and protection

- Identity profile and pending learnings are included in export/import and Firebase Cloud Brain sync.
- Manual identity edits, accepted/rejected learning and development-stage changes are audited.
- External actions, money, destructive changes and production changes remain approval-gated.

## Private Dylan Seed Vault

- A full personal seed can be imported through **Settings → Backup / Restore** without committing it to the public repository.
- Private sections cover relationships, history, health context, heritage, work, finances, creative identity, projects, worldview, working preferences and current priorities.
- The imported vault appears under **More → Core** and is used in identity-aware replies unless local-only privacy mode is selected.

## Test path

1. Open **More → Core** and review the confirmed profile.
2. In Talk, say: `I prefer short practical answers with the exact next step.`
3. Return to Core and accept or reject the proposed learning.
4. Ask: `Based on who I am, which project should I focus on today and why?`
5. Confirm that the answer uses family, freedom, assets, current projects and Dylan’s direct communication style.
