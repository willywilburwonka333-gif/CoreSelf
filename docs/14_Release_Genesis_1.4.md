# Genesis 1.4 — Second-Self Runtime

Genesis 1.4 changes Core Self from a collection of useful engines into an integrated second-self runtime.

## Core runtime

The new Second-Self Runtime connects:

1. Perceive — conversation, activity and project state.
2. Remember — Identity Core, Private Seed Vault and confirmed memories.
3. Reason — projects, goals, risks, relationships and prior outcomes.
4. Plan — ranked next moves and action stacks.
5. Act — deterministic internal tools now execute real underlying engines.
6. Reflect — completed actions become execution evidence for future reasoning.

The runtime exposes evidence-based capability telemetry instead of pretending every layer is complete.

## Memory Brain

- Contextual retrieval now scores lexical matches, phrase matches, relationships, importance, permanence and recency.
- Duplicate and possible-contradiction detection surfaces review candidates without silently changing memory.
- Memory integrity scoring tracks confirmation, permanence, tagging, pending suggestions and stale context.
- Low-signal memories can be identified for later consolidation.

## Execution learning

Completed Action Queue items create outcome records. Core Self can use these records as modest evidence when ranking future work.

Small samples are explicitly treated as low-confidence evidence. Dylan remains the final authority.

The twin combines confirmed identity context, memories, projects, goals, graph nodes, relationship links and action outcomes.

## Operator runtime

Safe internal tools now run their actual deterministic engines, including:

- Memory Recall
- Memory Compression
- Knowledge Graph
- Planning Engine
- AI Orchestrator
- Research Comparator
- Creator and Developer planning
- Business Builder
- Provider Status Map
- Action Queue

External communication, money, destructive actions and production writes remain behind setup and approval gates.

## Cloud Brain

Genesis 1.4 persists the newer runtime state that earlier releases left device-local:

- plans
- action queue
- tool registry
- tool execution history
- operator work log
- execution outcomes

These now participate in export/import and Firebase Cloud Brain sync.

## Offline Dylan Core

Offline deterministic reasoning now covers identity, family, priorities, memories, projects, goals, decisions, music/creative work, career, financial context, businesses and worldview.

Genesis 1.4 is still not a locally hosted language model. Open-ended generation and general reasoning still require a configured online provider.

## Interface

Genesis 1.4 introduces a new neural command-deck visual system:

## Privacy

The Private Dylan Seed Vault remains outside the public repository. It is imported into Dylan's signed-in Core Self session and may sync to his user-scoped Cloud Brain.

## Known external dependencies

These cannot be made 100% from repository code alone:

- Email / Calendar / Drive OAuth
- GitHub / Vercel / Firebase privileged operator credentials
- third-party video/music/voice provider APIs
- a real local/offline language model runtime
- years of Dylan-specific execution history needed for a mature behavioural model
