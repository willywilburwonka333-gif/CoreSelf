Privacy boundaries

The code runs in your browser and makes no network requests with your chat messages. However, this website's source is hosted publicly via GitHub Pages; anyone with the address can open their own empty version. GitHub and network operators may collect website access data. Your vault passphrase and decrypted notes stay on your device, but an unlocked device or compromised browser may expose them.

For maximum privacy, a future edition should run in a trusted fully local app, rather than public web hosting. This preview is not a substitute for an expert adviser or a real-world guardian.
